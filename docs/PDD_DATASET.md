# ПДД РФ: корпус для RAG

Снимок собран 30 октября 2026 года. Файлы находятся в `data/pdd/`, готовый индекс — в `artifacts/indices/pdd/`. ПДД — единственная рабочая база личного RAG и открывается автоматически. Изображения знаков показываются прямо в ответе; по просьбе о фото добавляются связанные снимки RTSD. [Как устроены ответы и проверка](PDD_SERVICE.md).

## Что включено

- Все 26 разделов ПДД, утвержденных постановлением №1090, редакция от **28.08.2026**; в том числе изменения электронного предъявления документов, действующие с 08.09.2026.
- Все восемь групп дорожных знаков, горизонтальная и вертикальная разметка, основные положения по допуску транспортных средств, десять разделов перечня неисправностей.
- Действующие статьи главы 12 КоАП и связанные статьи 2.6.1, 27.12, 27.12.1, 27.13, 30.1–30.3, 32.2, 32.6, 32.7. Редакция КоАП по заголовку источника: **04.08.2026**.
- Статьи УК 264, 264.1–264.3, 266–268; действующие статьи 196-ФЗ «О безопасности дорожного движения» и 40-ФЗ «Об ОСАГО».
- Основные разделы и таблицы ГОСТ Р 52289-2019 в редакции от **22.07.2025**, включая изменения №1 с 01.01.2026 и №2 с 01.07.2026. Графические приложения этого стандарта не заявлены как полный оцифрованный корпус.
- **308 эталонных изображений** 308 кодов из приложения А ГОСТ Р 52290-2024, в том числе 5.41, 5.42, 6.2.1, 6.16.1, 8.15.1, 8.16.2. Это иллюстрации из стандарта, полученные из открытой HTML-публикации, без генерации изображений.
- **432 реальных фотографии-фрагмента** 125 кодов знаков и 155 исходных классов, включая числовые варианты ограничения скорости. Отобрано до трёх наиболее крупных различных кадров на исходный класс, размером от 48×48. Исходный RTSD mirror parquet также сохранён: **104 358 записей**, 58 343 345 байт. Фотографии исторические; они не являются свидетельством действующей редакции закона.

Окончательные количества, хеши и редакции находятся в `manifest.json` и `coverage.json`. Это нормативный корпус с дополнительными справочными изображениями; он не включает все судебные решения, региональные акты, экзаменационные билеты и авторские статьи из интернета.

## Форматы

| Файл | Назначение |
|---|---|
| `dataset.json` | Готовый `Dataset` нашего RAG: `id`, `text`, `title`, `url` |
| `corpus.jsonl` | Текст, тип документа, пункт/статья, редакция, статус, источники, хеши и связи с изображениями |
| `signs.jsonl` | Код знака, название, PNG, размеры, SHA-256, ссылки на ПДД и правила применения |
| `photos.jsonl` | Фото, код класса, исходный ID RTSD, pinned revision, ограничения использования |
| `sources.json` | URL, фактическое время загрузки, MIME-тип, путь к оригиналу и SHA-256 |
| `coverage.json` | Проверка покрытия разделов и статистика изображений |
| `raw/` | Сохранённые HTML-оригиналы и полный parquet фотографий |
| `images/signs/` | Эталонные иллюстрации |
| `images/photos/` | Небольшая выборка реальных фотографий |

Текст разбит по пунктам, статьи сохранены целиком. Правовые сноски и таблицы сохраняются; навигация сайта, редакционные примечания, история замен и ссылки на прошлые редакции не индексируются. Отменённые самостоятельные пункты не включаются в активный набор. Снимки оригинальных страниц остаются для проверки.

Карточки знаков содержат описание из ПДД, когда найдено точное соответствие, и связанный пункт ГОСТ о применении. Общие исключения следует смотреть также в полной группе знаков. Если отдельного кода ещё нет в загруженном приложении ПДД, карточка явно сообщает об этом; название из ГОСТ не подменяется выдуманной нормой ПДД.

## Источники и проверка актуальности

Консолидированные тексты получены из открытых публикаций [ПДД](https://www.consultant.ru/document/cons_doc_LAW_2709/), [КоАП](https://www.consultant.ru/document/cons_doc_LAW_34661/), [ГОСТ Р 52289-2019](https://www.consultant.ru/document/cons_doc_LAW_348566/) в КонсультантПлюс. Это издательские консолидированные версии, а не самостоятельно восстановленная официальная редакция каждого акта. Для 196-ФЗ дата определяется по последнему изменяющему акту в списке издателя, поскольку дата редакции в заголовке отсутствует.

Действие стандартов сверено с официальными карточками Росстандарта: [52290-2024](https://protect.gost.ru/gost/details/39b75217-29bd-492b-94f4-c0dccb72b299), [52289-2019](https://protect.gost.ru/gost/details/94160176-3252-4e7d-8534-2d172e6aa0de). Изображения извлечены из [приложения А ГОСТ Р 52290-2024](https://rags.ru/documents/dop_documents/0/odm/0/gost.html).

Официальный портал публикации [постановления №1088](https://publication.pravo.gov.ru/document/0001202608310048) при сборке не ответил. Изменение присутствует в сохраненном консолидированном пункте 2.1.1, но независимая сверка с файлом официального опубликования остаётся ограничением и записана в manifest.

У ГОСТ Р 52290-2024 есть поправка с **10.08.2026**, зарегистрированная 28.07.2026: [официальная карточка](https://protect.gost.ru/gost/changesdetails/5e229d99-c816-43b1-ac09-ae7b63eb4879). По [тексту поправки в ГАРАНТ](https://base.garant.ru/414741817/) она исправляет ширину литерной площадки в приложении Г, таблице Г.3: 167 → 267. Приложение А с изображениями знаков не затрагивается. Полный текст технических таблиц ГОСТ Р 52290-2024 не заявляется как нормализованный корпус; в `raw` сохранён исходник.

Актуальность означает проверенный снимок на указанную дату. При обновлении нужно повторно проверить вступление изменений в силу и новые поправки к стандартам; одна дата скачивания не гарантирует юридическую полноту.

В карточках найденных фотодатасетов нет явной лицензии, разрешающей любое повторное распространение. Это отмечено у каждой фотографии; перед публичной публикацией корпуса или обучением коммерческой модели необходимо уточнить права у исходных авторов. Набору не назначается общая CC-лицензия. Для официальных текстов нормативных актов указана категория пп. 1 п. 6 ст. 1259 ГК РФ; права на оформление сайтов и авторские комментарии не переносятся в корпус. Для стандартов и изображений сохранена атрибуция без утверждения об общей открытой лицензии.

## Команды

```powershell
.\.venv\Scripts\python.exe -X utf8 -m raglab.cli prepare --dataset pdd
.\.venv\Scripts\python.exe -X utf8 -m raglab.cli index --dataset pdd
.\.venv\Scripts\python.exe -X utf8 -m raglab.pdd --verify
```

Обновление источников выполняется явно:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m raglab.pdd --refresh
.\.venv\Scripts\python.exe -X utf8 -m raglab.cli index --dataset pdd --rebuild
```

Повторный запуск без `--refresh` использует проверенные по хешам исходники и завершает прерванную загрузку. Обновление не происходит автоматически при вопросах к RAG. Не запускайте обновление одновременно с вопросами к этой базе.

`--verify` проверяет хеши корпуса и оригиналов, чтение всех изображений, покрытие 26 разделов, обязательные новые коды и отсутствие оборванных ссылок. Независимых gold-вопросов и qrels пока нет: команды benchmark/evaluate/qa для ПДД не выдают искусственные метрики. Чат использует текстовый поиск; при явном вопросе о знаке с номером его карточка дополнительно находится по точному коду. Картинки показываются у найденных карточек знаков. Распознавание загруженного пользователем фото не реализовано. Результаты смыслового поиска требуют проверки: диагностика на восьми вопросах не заменяет независимую оценку качества.
